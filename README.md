# Student Management System

A full-stack Student Management System built using the MERN Stack. The project allows users to manage student and faculty records through a simple and user-friendly interface.

## Features

- Student CRUD (Add, View, Edit, Delete)
- Faculty CRUD (Add, View, Edit, Delete)
- Student Search
- Dashboard
- Analytics
- Attendance
- Fee Management
- Reports
- Profile Page

## Technologies Used

Frontend:
- React.js
- Bootstrap
- Axios
- React Router

Backend:
- Node.js
- Express.js

Database:
- MongoDB
- Mongoose

## Installation

# Backend

```bash
cd server
npm install
npm run dev
```

# Frontend

```bash
cd client
npm install
npm run dev
```
